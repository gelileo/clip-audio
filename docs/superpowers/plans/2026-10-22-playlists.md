# Playlists & Favorites Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add user-created playlists and a built-in Favorites playlist to ClipAudio, persisted as JSON, with a heart button that adds the currently playing track to Favorites.

**Architecture:** A pure-Swift storage layer (`PlaylistStorage`) handles file IO and is unit-testable with no simulator. A `@MainActor` `PlaylistStore` owns the in-memory array and publishes to SwiftUI. `AudioPlayer` gains a way to play a playlist but never references the store — views mediate. Metadata is backfilled in the background so adding is instant.

**Tech Stack:** Swift 5 language mode, SwiftUI, Foundation `Codable`, Swift Testing (`import Testing`), xcodegen, Xcode 26 / iOS 17 target.

**Spec:** `docs/superpowers/specs/2026-10-22-playlists-design.md` — read it before Task 1. The plan argues from the spec; both travel together.

## Global Constraints

- **The project is NOT a git repository.** Every task's final step is "verify build and tests green" rather than a commit. If `git init` has been run by the time you execute, commit at each of those points instead.
- `ios/project.yml` is the source of truth. **Never hand-edit `ios/ClipAudio.xcodeproj`** — it is gitignored and regenerated by `xcodegen generate`.
- Deployment target iOS 17.0; `SWIFT_VERSION` 5.0.
- **No resolved stream URL may ever be persisted** (PRD C8). `PlaylistItem` has no field for one. Do not add one.
- `AudioPlayer` must not import or reference `PlaylistStore`. Dependency runs one way.
- Storage path: `Application Support/ClipAudio/playlists.json`.
- `PlaylistFile.schemaVersion` current value is `1`.
- `maxMetadataAttempts = 3`.
- Favorites: name exactly `"Favorites"`, `isFavorites == true`, always index 0, cannot be renamed or deleted.
- Save debounce: 0.5s, coalesced.
- Build check used throughout:
  `cd ios && xcodegen generate && xcodebuild -project ClipAudio.xcodeproj -scheme ClipAudio -destination 'platform=iOS Simulator,id=F7E32EA5-98B0-4F53-A788-6B99C23285FF' -derivedDataPath build/dd -quiet build`
- Test check used throughout:
  `cd ios && xcodebuild test -project ClipAudio.xcodeproj -scheme ClipAudio -destination 'platform=iOS Simulator,id=F7E32EA5-98B0-4F53-A788-6B99C23285FF' -derivedDataPath build/dd -quiet`

## Review Focus

Input classes the spec implies but which no task's happy-path tests would otherwise exercise. Each has a test assigned to the task that owns the code.

1. **Empty or whitespace-only playlist name** on create or rename — should be rejected, not stored as a blank row. *(Task 3)*
2. **Zero-byte or truncated store file** — distinct from malformed JSON, and a likely result of a crash on an older build. Must recover like corruption, not crash. *(Task 2)*
3. **Removing the item that is currently playing** — the queue holds a copy, so playback must continue unaffected rather than crash on an index that moved. *(Task 5)*
4. **Backfill completing for an item the user deleted mid-flight** — the write-back must be a no-op, not an index-out-of-range. *(Task 4)*
5. **Two playlists with the same name** — allowed (names are not identity; `id` is), but must not break lookup or the picker. *(Task 3)*

```swift
import Foundation

/// A saved reference to something playable.
///
/// Storage type, deliberately distinct from `Track` (playback). It has no
/// field for a resolved stream URL: PRD C8 says those expire and are client-
/// bound, so the type system — not discipline — keeps them out of the library.
struct PlaylistItem: Identifiable, Codable, Hashable {
    let id: UUID
    let sourceURL: String
    var title: String?
    var uploader: String?
    var duration: Double?
    var artworkURL: String?
    var addedAt: Date
    var metadataFetchedAt: Date?
    var metadataAttempts: Int
    var unavailable: Bool

    init(id: UUID = UUID(),
         sourceURL: String,
         title: String? = nil,
         uploader: String? = nil,
         duration: Double? = nil,
         artworkURL: String? = nil,
         addedAt: Date = Date(),
         metadataFetchedAt: Date? = nil,
         metadataAttempts: Int = 0,
         unavailable: Bool = false) {
        self.id = id
        self.sourceURL = sourceURL
        self.title = title
        self.uploader = uploader
        self.duration = duration
        self.artworkURL = artworkURL
        self.addedAt = addedAt
        self.metadataFetchedAt = metadataFetchedAt
        self.metadataAttempts = metadataAttempts
        self.unavailable = unavailable
    }

    var hasMetadata: Bool { metadataFetchedAt != nil }
    var displayTitle: String { title ?? sourceURL }
}

struct Playlist: Identifiable, Codable, Hashable {
    let id: UUID
    var name: String
    var isFavorites: Bool
    var items: [PlaylistItem]
    var createdAt: Date

    init(id: UUID = UUID(),
         name: String,
         isFavorites: Bool = false,
         items: [PlaylistItem] = [],
         createdAt: Date = Date()) {
        self.id = id
        self.name = name
        self.isFavorites = isFavorites
        self.items = items
        self.createdAt = createdAt
    }

    func contains(sourceURL: String) -> Bool {
        items.contains { $0.sourceURL == sourceURL }
    }
}

struct PlaylistFile: Codable {
    static let currentSchemaVersion = 1
    var schemaVersion: Int
    var playlists: [Playlist]
}

enum AddOutcome: Equatable {
    case added(PlaylistItem)
    case alreadyPresent(PlaylistItem)
}

/// Metadata only. Exists so backfill cannot carry a stream URL into storage.
struct ResolvedMetadata: Equatable {
    let title: String?
    let uploader: String?
    let duration: Double?
    let artworkURL: String?
}

extension PlaylistItem {
    /// Snapshot a playback Track for storage. Drops streamURL/formatID/resolvedAt.
    init(from track: Track) {
        self.init(sourceURL: track.sourceURL,
                  title: track.title,
                  uploader: track.uploader,
                  duration: track.duration,
                  artworkURL: track.artworkURL,
                  metadataFetchedAt: track.title == nil ? nil : Date())
    }

    mutating func apply(_ m: ResolvedMetadata) {
        title = m.title ?? title
        uploader = m.uploader ?? uploader
        duration = m.duration ?? duration
        artworkURL = m.artworkURL ?? artworkURL
        metadataFetchedAt = Date()
    }
}

extension Track {
    /// Build a playable Track from a stored item. Unresolved by construction.
    init(from item: PlaylistItem) {
        self.init(sourceURL: item.sourceURL)
        self.title = item.title
        self.uploader = item.uploader
        self.duration = item.duration
        self.artworkURL = item.artworkURL
    }
}
```

Create `ios/ClipAudio/Playlists/PlaylistStorage.swift`:

```swift
import Foundation

protocol PlaylistSerializing: Sendable {
    func encode(_ file: PlaylistFile) throws -> Data
}

struct JSONPlaylistSerializer: PlaylistSerializing {
    func encode(_ file: PlaylistFile) throws -> Data {
        let e = JSONEncoder()
        e.outputFormatting = [.prettyPrinted, .sortedKeys]
        return try e.encode(file)
    }
}

/// All file IO for the playlist library. Deliberately not `@MainActor` and
/// free of SwiftUI, so the whole of it is unit-testable with no simulator.
struct PlaylistStorage {
    enum StorageError: Error, Equatable {
        case readOnlyNewerSchema(found: Int, supported: Int)
    }

    enum LoadResult {
        case loaded(PlaylistFile)
        /// Nothing usable on disk. `recoveredFrom` names the preserved bad file, if any.
        case seeded(PlaylistFile, recoveredFrom: URL?)
        /// Written by a newer build: usable, but we must not write over it.
        case readOnly(PlaylistFile)
    }

    let directory: URL
    private let serializer: PlaylistSerializing
    private let fm = FileManager.default

    init(directory: URL, serializer: PlaylistSerializing = JSONPlaylistSerializer()) {
        self.directory = directory
        self.serializer = serializer
    }

    var fileURL: URL { directory.appendingPathComponent("playlists.json") }

    static func seededFile() -> PlaylistFile {
        PlaylistFile(schemaVersion: PlaylistFile.currentSchemaVersion,
                     playlists: [Playlist(name: "Favorites", isFavorites: true)])
    }

    func load() -> LoadResult {
        guard let data = try? Data(contentsOf: fileURL), !data.isEmpty else {
            // Missing is normal on first launch. Empty is not — a zero-byte
            // file means a previous write died, so preserve it like corruption.
            let recovered = fm.fileExists(atPath: fileURL.path) ? quarantine() : nil
            return .seeded(Self.seededFile(), recoveredFrom: recovered)
        }
        guard let file = try? JSONDecoder().decode(PlaylistFile.self, from: data) else {
            return .seeded(Self.seededFile(), recoveredFrom: quarantine())
        }
        if file.schemaVersion > PlaylistFile.currentSchemaVersion {
            return .readOnly(file)
        }
        return .loaded(migrate(file))
    }

    func save(_ file: PlaylistFile) throws {
        guard file.schemaVersion <= PlaylistFile.currentSchemaVersion else {
            throw StorageError.readOnlyNewerSchema(
                found: file.schemaVersion, supported: PlaylistFile.currentSchemaVersion)
        }
        try fm.createDirectory(at: directory, withIntermediateDirectories: true)

        // Encode before touching the destination: a serializer failure must
        // leave the existing library exactly as it was.
        var out = file
        out.schemaVersion = PlaylistFile.currentSchemaVersion
        let data = try serializer.encode(out)

        let tmp = directory.appendingPathComponent("playlists.\(UUID().uuidString).tmp")
        try data.write(to: tmp, options: .atomic)
        if fm.fileExists(atPath: fileURL.path) {
            _ = try fm.replaceItemAt(fileURL, withItemAt: tmp)
        } else {
            try fm.moveItem(at: tmp, to: fileURL)
        }
    }

    /// v1 is the initial version, so this is the identity case today. It
    /// exists so a future v2 has an obvious home.
    private func migrate(_ file: PlaylistFile) -> PlaylistFile {
        switch file.schemaVersion {
        case PlaylistFile.currentSchemaVersion: return file
        default: return file
        }
    }

    /// Move an unreadable file aside. Never delete it — it is the user's data.
    private func quarantine() -> URL? {
        let stamp = ISO8601DateFormatter().string(from: Date())
            .replacingOccurrences(of: ":", with: "-")
        let dest = directory.appendingPathComponent("playlists.corrupt-\(stamp).json")
        do { try fm.moveItem(at: fileURL, to: dest); return dest } catch { return nil }
    }
}
```

```swift
import Combine
import Foundation

/// Owns the playlist library in memory and publishes it to SwiftUI.
/// All file IO is delegated to `PlaylistStorage`.
@MainActor
final class PlaylistStore: ObservableObject {
    enum StoreError: Error, Equatable {
        case blankName
        case favoritesImmutable
    }

    @Published private(set) var playlists: [Playlist] = []
    /// Set when something happened the user should know about (recovered a
    /// corrupt file, or the library was written by a newer build).
    @Published private(set) var statusMessage: String?
    @Published private(set) var isReadOnly = false

    static let shared = PlaylistStore()

    private let storage: PlaylistStorage
    private var saveTask: Task<Void, Never>?
    private let saveDebounce: Duration = .milliseconds(500)

    init(storage: PlaylistStorage) {
        self.storage = storage
        switch storage.load() {
        case let .loaded(file):
            playlists = file.playlists
        case let .seeded(file, recovered):
            playlists = file.playlists
            if let r = recovered {
                statusMessage = "Your playlist file couldn't be read and was kept as "
                    + "\(r.lastPathComponent). Starting fresh."
            }
        case let .readOnly(file):
            playlists = file.playlists
            isReadOnly = true
            statusMessage = "This library was written by a newer version of ClipAudio. "
                + "It's shown read-only so nothing is overwritten."
        }
        ensureFavoritesPinned()
    }

    private convenience init() {
        let base = FileManager.default
            .urls(for: .applicationSupportDirectory, in: .userDomainMask)[0]
            .appendingPathComponent("ClipAudio", isDirectory: true)
        self.init(storage: PlaylistStorage(directory: base))
    }

    var favorites: Playlist {
        playlists.first { $0.isFavorites } ?? Playlist(name: "Favorites", isFavorites: true)
    }

    // MARK: - Playlists

    @discardableResult
    func createPlaylist(name: String) throws -> Playlist {
        let trimmed = name.trimmingCharacters(in: .whitespacesAndNewlines)
        guard !trimmed.isEmpty else { throw StoreError.blankName }
        let p = Playlist(name: trimmed)
        playlists.append(p)
        scheduleSave()
        return p
    }

    func renamePlaylist(id: UUID, to name: String) throws {
        guard let i = playlists.firstIndex(where: { $0.id == id }) else { return }
        guard !playlists[i].isFavorites else { throw StoreError.favoritesImmutable }
        let trimmed = name.trimmingCharacters(in: .whitespacesAndNewlines)
        guard !trimmed.isEmpty else { throw StoreError.blankName }
        playlists[i].name = trimmed
        scheduleSave()
    }

    func deletePlaylist(id: UUID) throws {
        guard let i = playlists.firstIndex(where: { $0.id == id }) else { return }
        guard !playlists[i].isFavorites else { throw StoreError.favoritesImmutable }
        playlists.remove(at: i)
        scheduleSave()
    }

    /// Favorites is pinned, so a move is applied and then Favorites is
    /// re-asserted at index 0 regardless of where the drag landed.
    func movePlaylists(fromOffsets: IndexSet, toOffset: Int) {
        playlists.move(fromOffsets: fromOffsets, toOffset: toOffset)
        ensureFavoritesPinned()
        scheduleSave()
    }

    private func ensureFavoritesPinned() {
        if let i = playlists.firstIndex(where: { $0.isFavorites }), i != 0 {
            let f = playlists.remove(at: i)
            playlists.insert(f, at: 0)
        }
        if !playlists.contains(where: { $0.isFavorites }) {
            playlists.insert(Playlist(name: "Favorites", isFavorites: true), at: 0)
        }
    }

    // MARK: - Items

    @discardableResult
    func add(sourceURL: String, to playlistID: UUID) -> AddOutcome? {
        add(item: PlaylistItem(sourceURL: sourceURL), to: playlistID)
    }

    @discardableResult
    func add(track: Track, to playlistID: UUID) -> AddOutcome? {
        add(item: PlaylistItem(from: track), to: playlistID)
    }

    private func add(item: PlaylistItem, to playlistID: UUID) -> AddOutcome? {
        guard let i = playlists.firstIndex(where: { $0.id == playlistID }) else { return nil }
        if let existing = playlists[i].items.first(where: { $0.sourceURL == item.sourceURL }) {
            return .alreadyPresent(existing)
        }
        playlists[i].items.append(item)
        scheduleSave()
        return .added(item)
    }

    func remove(itemID: UUID, from playlistID: UUID) {
        guard let i = playlists.firstIndex(where: { $0.id == playlistID }) else { return }
        playlists[i].items.removeAll { $0.id == itemID }
        scheduleSave()
    }

    func moveItems(in playlistID: UUID, fromOffsets: IndexSet, toOffset: Int) {
        guard let i = playlists.firstIndex(where: { $0.id == playlistID }) else { return }
        playlists[i].items.move(fromOffsets: fromOffsets, toOffset: toOffset)
        scheduleSave()
    }

    // MARK: - Favorites shortcut

    func isFavorited(sourceURL: String) -> Bool {
        favorites.contains(sourceURL: sourceURL)
    }

    /// Returns the new state: true if now favorited.
    @discardableResult
    func toggleFavorite(sourceURL: String, metadataFrom track: Track?) -> Bool {
        guard let i = playlists.firstIndex(where: { $0.isFavorites }) else { return false }
        if let existing = playlists[i].items.first(where: { $0.sourceURL == sourceURL }) {
            playlists[i].items.removeAll { $0.id == existing.id }
            scheduleSave()
            return false
        }
        // Hearting what is already playing costs no extra network: the Track
        // carries the metadata, so the backfiller will skip this item.
        let item = track.map { PlaylistItem(from: $0) } ?? PlaylistItem(sourceURL: sourceURL)
        playlists[i].items.append(item)
        scheduleSave()
        return true
    }

    // MARK: - Metadata

    func applyMetadata(_ m: ResolvedMetadata, toItemID itemID: UUID, in playlistID: UUID) {
        guard let p = playlists.firstIndex(where: { $0.id == playlistID }),
              let i = playlists[p].items.firstIndex(where: { $0.id == itemID })
        else { return }   // user deleted it mid-flight; nothing to do
        playlists[p].items[i].apply(m)
        scheduleSave()
    }

    func recordMetadataFailure(itemID: UUID, in playlistID: UUID) {
        guard let p = playlists.firstIndex(where: { $0.id == playlistID }),
              let i = playlists[p].items.firstIndex(where: { $0.id == itemID })
        else { return }
        playlists[p].items[i].metadataAttempts += 1
        scheduleSave()
    }

    func retryMetadata(itemID: UUID, in playlistID: UUID) {
        guard let p = playlists.firstIndex(where: { $0.id == playlistID }),
              let i = playlists[p].items.firstIndex(where: { $0.id == itemID })
        else { return }
        playlists[p].items[i].metadataAttempts = 0
        scheduleSave()
    }

    func markUnavailable(itemID: UUID, in playlistID: UUID) {
        guard let p = playlists.firstIndex(where: { $0.id == playlistID }),
              let i = playlists[p].items.firstIndex(where: { $0.id == itemID })
        else { return }
        playlists[p].items[i].unavailable = true
        scheduleSave()
    }

    func itemsNeedingMetadata(limit: Int) -> [(playlistID: UUID, item: PlaylistItem)] {
        var out: [(UUID, PlaylistItem)] = []
        for p in playlists {
            for item in p.items
            where item.metadataFetchedAt == nil
                && !item.unavailable
                && item.metadataAttempts < MetadataBackfiller.maxMetadataAttempts {
                out.append((p.id, item))
                if out.count >= limit { return out }
            }
        }
        return out
    }

    // MARK: - Persistence

    private func scheduleSave() {
        guard !isReadOnly else { return }
        saveTask?.cancel()
        let snapshot = playlists
        saveTask = Task { [weak self] in
            try? await Task.sleep(for: self?.saveDebounce ?? .milliseconds(500))
            guard !Task.isCancelled, let self else { return }
            self.write(snapshot)
        }
    }

    /// Bypass the debounce. Tests and app-background use this.
    func flushForTesting() {
        saveTask?.cancel()
        write(playlists)
    }

    func flush() { flushForTesting() }

    private func write(_ snapshot: [Playlist]) {
        do {
            try storage.save(PlaylistFile(
                schemaVersion: PlaylistFile.currentSchemaVersion, playlists: snapshot))
        } catch {
            statusMessage = "Couldn't save playlists: \(error.localizedDescription)"
        }
    }

    func dismissStatus() { statusMessage = nil }
}
```

```swift
import Foundation

/// Fills in titles, artwork and durations for items added without them.
///
/// Adding must be instant — blocking a heart-tap on a ~2s network resolve
/// makes it feel broken — but a library of untitled URLs is useless. So the
/// add is cheap and this runs behind it.
@MainActor
final class MetadataBackfiller {
    static let maxMetadataAttempts = 3
    private static let concurrency = 2

    private let store: PlaylistStore
    private let source: StreamSource
    private var loop: Task<Void, Never>?

    init(store: PlaylistStore, source: StreamSource) {
        self.store = store
        self.source = source
    }

    /// Resolve one batch. Separate from `start()` so tests can step it.
    func runOnce() async {
        let batch = store.itemsNeedingMetadata(limit: Self.concurrency)
        guard !batch.isEmpty else { return }

        await withTaskGroup(of: (UUID, UUID, Track?).self) { group in
            for (playlistID, item) in batch {
                group.addTask { [source] in
                    let track = try? await source.resolve(item.sourceURL)
                    return (playlistID, item.id, track)
                }
            }
            for await (playlistID, itemID, track) in group {
                if let t = track {
                    // Copy metadata only. The stream URL is deliberately dropped:
                    // PRD C8 forbids persisting it, and ResolvedMetadata has no
                    // field for it.
                    store.applyMetadata(
                        ResolvedMetadata(title: t.title,
                                         uploader: t.uploader,
                                         duration: t.duration,
                                         artworkURL: t.artworkURL),
                        toItemID: itemID, in: playlistID)
                } else {
                    store.recordMetadataFailure(itemID: itemID, in: playlistID)
                }
            }
        }
    }

    /// Run batches until nothing is left. Foreground only — call `stop()`
    /// when the app backgrounds.
    func start() {
        guard loop == nil else { return }
        loop = Task { [weak self] in
            while !Task.isCancelled {
                guard let self else { return }
                let before = self.store.itemsNeedingMetadata(limit: 1).count
                if before == 0 { break }
                await self.runOnce()
                try? await Task.sleep(for: .milliseconds(250))
            }
            self?.loop = nil
        }
    }

    func stop() {
        loop?.cancel()
        loop = nil
    }
}
```

```swift
struct PlaylistDetailView: View {

            .onMove { from, to in

            }
        }

        .navigationBarTitleDisplayMode(.inline)
        .toolbar { ToolbarItem(placement: .topBarTrailing) { EditButton() } }

                .lineLimit(1)
                .foregroundStyle(item.unavailable ? .secondary : .primary)
            HStack(spacing: 6) {

                    Text("Unavailable").font(.caption2).foregroundStyle(.orange)

                        Text("Loading…").font(.caption2).foregroundStyle(.secondary)
                    }
                } else {
                    if let u = item.uploader {
                        Text(u).font(.caption2).foregroundStyle(.secondary).lineLimit(1)
                    }

                        Text(durationText(d)).font(.caption2.monospacedDigit())

    private func durationText(_ t: Double) -> String {
```

- [ ] **Step 1: Wire it up**

```swift
    @State private var backfiller: MetadataBackfiller?
```

Add these modifiers to the `TabView`:

```swift
        .task {
            let bf = MetadataBackfiller(store: store, source: YtDlpStreamSource())
            backfiller = bf
            bf.start()
        }
        .onChange(of: scenePhase) { _, phase in
            switch phase {
            case .active:
                backfiller?.start()
            case .background, .inactive:
                // Backgrounded WKWebView/network work is throttled, and a
                // debounced save could be lost if we are suspended (PRD C9).
                backfiller?.stop()
                store.flush()
            @unknown default:
                break
            }
        }
```
